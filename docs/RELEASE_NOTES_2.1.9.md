A big fix release from your **Report a problem** reports - thank you.

## 🆕 New
- **Report a Problem inside the game**: MY WWE > OPTIONS > REPORT A PROBLEM, or REPORT A PROBLEM in the pause menu during a match (not online). Same questions as the launcher, a screenshot of the screen you were on (or add pictures later), and the match you were playing.
- **Reports tab** in the launcher (and **My reports** on Android): see the reports you've sent and whether each one is fixed for the next update - answer us when we need more information, or **edit a report** to add text or pictures you left out.
- **Android can send reports** straight to us now. Reports are sent only (no more saving or copying the report file).
- **Save cleaner** (launcher Saves tab, and Android): "Clean save of unused mods" removes the data of mods you've uninstalled or turned off from your save. It shows what it will remove first and always makes a backup (Restore backup puts it back).
- **Per-mod save files** 🧪 (launcher Saves tab, off by default): each mod superstar's save data - and their spots in teams, titles and Universe cards - lives in its own file, so your main save stays clean and a reinstalled mod gets its edits back.
- **Many more mod superstars** 🧪: mods are no longer tied to the game's fixed 137 slots - install as many as you like and use any of them anywhere.
- **Faster loading screens** (launcher Play tab / Android Game settings, off by default): the start-up loading screens play about 4x faster - roughly 6-8 seconds off every start. Their animations speed up while they show.
- **Bigger match memory**: the memory a match load uses went from 4.5 MB to 16 MB, so big mod setups (many superstars, crowd signs and move packs) load instead of stopping with "Out of game memory".
- **Brighter PlayStation buttons** in matches, and a plain keyboard picture at character select.
- **Online:** the ONLINE menu now counts only players looking for a match.
- **Android on Mali phones** now defaults to a steady 30 fps (pick 60 under Display if your phone keeps up).

## 🛠️ Fixes
- **Custom trons (entrance videos) black or not playing** for mods - fixed. Your existing install heals itself.
- **Superstar Threads showed the wrong face and parts** when playing above 1x render scale (e.g. 4K / 8K settings) - fixed.
- **Inferno, Ladder/TLC and Steel Cage on mod arenas** picked from the arena pages: no fire, no prize to grab, invisible cage - fixed.
- **Crashes at a modded superstar's entrance** (and Universe crashing before the second entrance) - fixed.
- **Road to WrestleMania, John Cena week 2**: the crash when MVP joins the backstage brawl - fixed.
- **Royal Rumble crashes** when an opponent had just been thrown out, and CPUs standing idle late in a Rumble - fixed.
- **A rare crash a moment into a match** (with entrances off) - fixed.
- **Online tag matches**: a player in the 3P (or 4P) slot next to CPU partners couldn't move - fixed. Fewer "You must have the same downloadable content" refusals when joining.
- **Keyboard prompts in matches** now show the key you actually use (reversal was always shown as E even if you play with O).
- **Low video memory** (older cards): the game now lowers the render scale instead of crashing, and switches graphics mode by itself if the device fails at start.
- **Crash reports** are now written even when the game is closed or frozen during a crash, so we can find more crashes.
- **The game crashed at every launch** for some players with move packs - the game now repairs its merged files.
- **The pause menu wouldn't open / the HUD vanished** after using the free camera keys (F4-F8) - fixed.
- **Bundled Mankind stood motionless** (now Mankind 2.0.4), **Sabu**'s finisher camera stays above the ring.
- **DLC John Cena (purple) and Undertaker (biker)** now get their names announced and real commentary.
- **The Japanese disc** isn't supported - the launcher and the game now say so clearly instead of closing. **Mac through Wine / CrossOver** also gets a clear message.
- **Old NVIDIA cards** (e.g. GeForce GT 430): broken wrestler skin on Direct3D 11 - fixed 🧪. Direct3D 11 is also smoother on slower PCs.
- **Launcher updates** survive GitHub's download limit and resume a cut download.
- **Android**: a match could freeze right after the entrances on some phones - fixed.
- **Mod Maker**:
  - converted superstars no longer disappear after converting several in a row;
  - SvR 2007 / 2008 ports: Rey Mysterio converts, The 619 ports, dives like the Swanton stay in the ring, SvR 2007 superstars no longer shine white or run on in Hell in a Cell (convert them again to get the fixes);
  - no more crash when adding pictures on Intel graphics 🧪;
  - "From another game" pickers open in the folder you used last for that game; a DLC-only folder now gets a clear note instead of a missing-files error.
- Faster first start after you change mods, a faster superstar select screen with many mods, and less renderer work per frame (smoother on slower PCs and phones).
