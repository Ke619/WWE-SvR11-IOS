Relay now 

    
Every game on the relay at this moment, busiest first. Every online game keeps the relay open to find sessions; packets a second counts what it tries to send one other game through it (a match: 60 and more). With the match network on p2p the relay passes a game only a few of those a second, whatever version it is: a busy one there is marked held back. Ban signs the account out and takes its games off the relay and the edge at once.

Storage audit 
      

    
Compares the files where the uploads' bytes live (the storage node) with what the database refers to. An orphan is a file nothing refers to (e.g. a delete while the node was down): it goes only with its Delete. Hidden mods are listed so they aren't mistaken for orphans.

    

  


  

    
Discovery comments 
      
      

    
Comments on Discovery mods, reported ones first. The server refuses links, invites, the name
      filter's words and the comment word list (Names tab) on its own. Hide takes a comment off the mod's page
      (Show puts it back); Delete removes it for good. Comments deleted by their writer or the mod's uploader stay
      here 30 days. Mute stops an account commenting (or commenting and upvoting). A mod's author can turn its
      comments off (Discovery tab: "comments off"): they stay listed here, hidden from players. The switches are on
      the Settings tab: discovery_comments, discovery_upvotes.

Name filter 

    
Checked on everything players put on the server: Community Creations titles, tags and comments,
      Discovery mods' names / tags / descriptions, entrance song and movie names, and account names (at sign-up, and an
      uploader's own name at each upload). A refused upload tells the player why ("That name isn't allowed on Community
      Creations"); nothing already on the server is changed - see Flagged names below.

    

    

      

        
        
One per line. Under 5 letters: a whole word only (and "f a g" spelled out), so
          "Scunthorpe" is fine; 5 or more: inside words too, and across words ("hit ler"). =word whole word
          only, *word inside words too, two words a phrase, # ... a note. Case, leetspeak (h1tl3r,
          @, $), repeated letters, dots / spaces / underscores between letters and look-alike letters are read
          through.

      

        
        
Words never flagged though a listed word is inside them (e.g. snigger). One per line.

    

    


    
Comment words (Discovery comments) 

    
A second list, for Discovery comments only, with the same rules as the name filter: talk of game
      copies (ISO, XEX, ROM, NSP, torrents, "download the game"...). Short words are read whole and spelled out too
      ("i s o", "i.s.o", "game.iso" - not "isolated"). Split archive names (.7z.001, .part1.rar) are refused as well.
      The name filter's list above is checked on comments too.
